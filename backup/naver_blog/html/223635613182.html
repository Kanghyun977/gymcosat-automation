견갑하근 기능

  • 견갑하근은 견관절과 상완관절의 안정화에 큰 역활을 하고, 상완골의 전방 전위를 예방하는데 도움이 됩니다. [어깨 근육 중 유일하게 상완골을 뒤로 보냄]

  • 견갑하근은 내측회전과 내전을 하며, 외전 시 상완골의 골두를 잡아당겨 견봉하공간에 점액낭이 압박되지 않게 안정성 역할을 함

​

​

견갑하근 기능 부재 원인

  • 근육이 견관절의 아탈구로 스트레스 받을 때

  • 위팔뼈의 골절이나 견관절낭이 찢어질 때

  • 내전과 내회전한 자세로 오랫동안 움직이지 않을 때

  • 머리를 앞쪽으로 내밀어 구부정한 자세를 오랫동안 유지할 때

​

견갑하근 기능 부재로 인한 증상

어깨 통증이 생김

​

  • 상완골이 계속 앞으로 전위되면서, 가슴근육, 전면 삼각근, 전면 팔근육들이 과하게 활성화되어, 견봉하증후군[어깨 충돌증후군]이라는 근골격계 문제에 노출되기 쉬워짐

​

  • 외전시 오목 위관절이 미끄러짐이 부족하여 견봉하공간 점액낭이 계속 마찰되어 염증반응을 일으킴 [ 염증이 절구까찌 유착된다면, 오십견이라고 진단을 하는 경우가 많음]

​

​

추가적으로

  • 견갑하근의 통증유발점을 치료가 되면 손저림, 팔 안쪽 통증이 감소되는 경우가 많음
